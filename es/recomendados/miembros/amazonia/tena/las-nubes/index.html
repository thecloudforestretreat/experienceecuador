Decide si conviene agregar esta parada

Anota las actividades que quieres hacer alrededor de Tena, dónde necesitas estar cada mañana y el tiempo entre conexiones fijas. Pide al alojamiento y al transportista que confirmen el recorrido desde la entrada real, no solo un cálculo entre poblaciones.

Compara dos opciones: mantener una base adecuada para las actividades de Tena o incluir el alojamiento de Cosanga como una parada independiente. Cuenta equipaje, salida, llegada y descanso. Evita contratar una actividad para el mismo día si depende de un traslado aún no confirmado.

Resuelve estas preguntas antes de reservar

Confirma propiedad y habitación exactas, fechas, acceso, comidas, servicios y salidas guiadas. Después solicita por escrito el precio total, inclusiones, pago y cancelaciones. Esta página no confirma disponibilidad vigente.

Si necesitas ayuda con una ruta más amplia, comparte fechas fijas, noches disponibles y las experiencias que conservarías si hubiera que acortar el viaje. El formulario regional sirve para una consulta, no para confirmar una reserva.
