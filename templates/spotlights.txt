SPOTLIGHTS TEMPLATE

PURPOSE
The Spotlights section is designed to showcase timely, seasonal, or noteworthy events and moments across Ecuador.

It is NOT a blog.
It is NOT evergreen content.

It should:
- highlight “what’s happening now” or “what’s worth knowing now”
- increase engagement and return visits
- support SEO freshness signals
- drive users into regions, experiences, and planning pages

CORE UX GOALS
1. Feel dynamic and current
2. Encourage exploration
3. Support internal linking
4. Provide quick, useful insights for travelers

PAGE TYPES
1. Spotlights Hub (/spotlights and /es/destacados)
2. (Future) Individual Spotlight Pages for major events

For now:
- Focus on Hub page only

SECTION ORDER (HUB PAGE)

1. Hero
2. Intro
3. Featured Spotlights
4. Latest Spotlights Grid
5. Filter / Categories (optional future)
6. Related Regions & Experiences
7. Trip Builder CTA
8. Final CTA

1. HERO
Purpose:
- introduce the concept of Spotlights

Content:
- H1
- short supporting paragraph

Example:
H1: Ecuador Travel Spotlights
Copy: Discover seasonal highlights, events, and unique travel moments happening across Ecuador.

Keep compact. No oversized hero.

2. INTRO
Purpose:
- explain what users will find

Content:
- 1 to 2 short paragraphs

Explain:
- seasonal highlights
- events
- wildlife moments
- travel timing insights

3. FEATURED SPOTLIGHTS
Purpose:
- highlight top 2 to 4 priority items

Content:
- large cards

Each card:
- image
- title
- short description
- region tag
- CTA (if applicable)

Examples:
- whale season on the coast
- bird migration in Mindo
- Quito festivals
- Amazon wildlife peak seasons

4. LATEST SPOTLIGHTS GRID
Purpose:
- show multiple spotlight items

Content:
- grid of cards

Each card:
- image
- title
- short description
- region label
- link (if expanded later)

Keep consistent card design.

5. FILTER / CATEGORIES (FUTURE)
Optional:
- by region
- by type (events, wildlife, seasonal)

Keep simple if implemented.

6. RELATED REGIONS & EXPERIENCES
Purpose:
- drive deeper exploration

Content:
- links or cards to:
  - region pages
  - experience pages

Example:
- Explore Andes
- Explore Birdwatching
- Explore Amazon

7. TRIP BUILDER CTA
Purpose:
- convert engagement into action

Content:
- short paragraph
- CTA button

Example:
Use these seasonal insights to build a smarter Ecuador itinerary.

8. FINAL CTA
Purpose:
- close strong

Content:
- 2 CTAs

Examples:
- Explore Regions
- Start Planning

IMAGE RULES
- strong, relevant visuals
- avoid generic stock
- each spotlight should feel unique

SPACING RULES
- no empty gaps
- tight grid alignment
- consistent spacing

MOBILE-FIRST RULES
- stacked cards
- simple grids
- readable text

DESKTOP RULES
- 2 to 4 column grid
- balanced layout

SEO REQUIREMENTS
- optimized title
- meta description
- H1 + H2 structure
- internal links to regions and experiences

CONVERSION REQUIREMENTS
- include CTAs to:
  - regions
  - experiences
  - trip builder

INTERNAL LINKING
Each spotlight should connect to:
- a region
- an experience
- possibly a guide page

CONTENT TONE
- timely
- engaging
- concise
- useful

DESIGN PRINCIPLE
Spotlights should feel like:
- a live travel feed
- curated insights
- seasonal intelligence

Not:
- a blog list
- static content
