MANDATORY SEO / SOCIAL / SCHEMA OUTPUT PACKAGE
==================================================
Before drafting the HTML body, silently lock this exact package:

1. Title (SEO optimized)
   - Max 60 characters.
   - Format: [Primary Keyword] | [Value]
   - Must include the pipe character.
   - Keyword-first and CTR-aware.

2. Meta Description
   - 140 to 160 characters.
   - Specific, high-CTR, and aligned with the real query intent.

3. H1 (aligned with title)
   - Must align with the SEO title.
   - May simplify the title for readability.
   - Usually remove the value phrase after the pipe unless repeating it is clearly better.

4. New OG Title
   - Must be the same as the SEO title.

5. New OG Description
   - Must be the same as the meta description.

6. New Schema Name
   - Must be the SEO title with the pipe removed.
   - Example: "Best Things to Do in Ecuador | Smart Guide" becomes "Best Things to Do in Ecuador Smart Guide".
   - Do not use a schema name that conflicts with the title.

7. New Schema Description
   - Must be the same as the meta description.

Apply this package consistently to:
- <title>
- meta description
- og:title
- og:description
- twitter:title
- twitter:description
- JSON-LD headline when relevant
- JSON-LD name
- JSON-LD description
