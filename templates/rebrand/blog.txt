BLOG / GUIDE PAGE TEMPLATE V3
EXPERIENCE ECUADOR
PRODUCTION TEMPLATE

PAGE TYPE
- This template is for BLOG / GUIDE PAGES for ExperienceEcuador.com
- Use for evergreen travel guides, comparison posts, itinerary posts, packing posts, city guides, and things-to-do posts
- Output must always be a COMPLETE, FULL, DROP-IN HTML FILE
- Never output partial sections
- Never output summaries instead of files
- Deliver as downloadable .txt files only

==================================================
MANDATORY PAGE STRUCTURE
==================================================

1. Hero
2. Intro (Hook + Context)
3. Quick Summary / Key Takeaways
4. Main Content Sections
5. Internal Linking Blocks (Inline)
6. Visual Break Sections (Optional)
7. Related Destinations / Experiences
8. Related Collections
9. FAQ
10. Final CTA

==================================================
1. HERO
==================================================
Required:
- H1
- 1 short supporting sentence
- Optional brand line: Experience Ecuador
- 1 hero image
- Visible EN / ES crawlable language links in raw HTML
- Do not rely only on hreflang or JS-injected nav for bilingual discovery

Hero rules:
- Keep concise
- No long intro paragraphs in hero
- H1 must align with the SEO title but read slightly cleaner
- Supporting sentence should reinforce search intent and value

Hero image rule:
- Use 1 strong hero image
- If no image is available, use the approved placeholder:
  https://experienceecuador.com/EE-OG-Image-1.jpg

==================================================
2. INTRO (HOOK + CONTEXT)
==================================================
Required:
- 2 to 3 short paragraphs
- Answer the intent immediately
- Clarify what the post will help the reader decide, compare, plan, or avoid
- Set expectations for what comes next

Rules:
- Answer first, explain second
- No fluff
- No generic travel-blog filler
- First paragraph should target the main search intent directly

==================================================
3. QUICK SUMMARY / KEY TAKEAWAYS
==================================================
Required:
- 4 to 6 bullets
- Fast answers for skimmers
- Must be useful, not repetitive

Typical content:
- Best for
- Best route fit
- Main tradeoff
- Who it suits
- Common mistake to avoid
- Best next step

==================================================
4. MAIN CONTENT SECTIONS
==================================================
Required:
- Use H2 and H3 hierarchy
- Short paragraphs only
- Lists and bullets preferred where useful
- Clear subtopics
- Must satisfy real search intent

Rules:
- H2s must be purposeful and keyword-aware
- H3s should clarify comparisons, planning logic, or sub-decisions
- Keep paragraphs to 2 to 4 lines max when possible
- Avoid vague generic statements
- Use practical decision language

Examples of suitable section types:
- What this page helps you decide
- Best options by traveler type
- Region-by-region comparison
- Common mistakes
- Route fit
- Packing, budget, time, logistics, or suitability
- How to choose between options
- What to do first
- Suggested planning logic

==================================================
5. INTERNAL LINKING (INLINE)
==================================================
Required:
- Links must appear naturally inside the article body
- Do not isolate all links in one footer-like block
- Use descriptive anchor text

Link naturally to:
- Destination pages
- Experience pages
- Collection pages
- Trip Builder
- Related guides
- Relevant comparison pages
- Relevant itinerary pages

English pages must naturally include:
- /trip-builder/
- /best-places-to-visit-in-ecuador/
- /where-to-stay-in-ecuador/

Spanish pages must naturally include:
- /es/planificador-de-viajes/
- /es/mejores-lugares-para-visitar-ecuador/
- /es/donde-alojarse-ecuador/

Spanish rule:
- Use ONLY sitemap-confirmed Spanish URLs
- Never invent Spanish slugs
- Never manually translate a URL unless confirmed

==================================================
6. VISUAL BREAK SECTIONS (OPTIONAL)
==================================================
Allowed:
- Highlight box
- Quote block
- Comparison block
- Image block
- Pull-quote
- Checklist block

Use:
- Every 2 to 3 sections if the page is long
- To break fatigue and improve scanability

Rules:
- Must stay lightweight
- No page-level CSS
- No inline component JS
- No decorative filler blocks with no informational value

==================================================
7. RELATED DESTINATIONS / EXPERIENCES
==================================================
Required:
- 3 to 6 cards
- Must help users go deeper
- Must be relevant to the article intent

Each card should include:
- image
- name
- short why-it-matters line
- CTA link

Rules:
- Link deeper into the ecosystem
- Use only valid URLs
- Use placeholder image if no valid image exists

==================================================
8. RELATED COLLECTIONS
==================================================
Required:
- 2 to 4 links or cards
- Must point to relevant high-level pages

Typical links:
- Best Places to Visit in Ecuador
- Where to Stay in Ecuador
- Ecuador Private Tours
- Ecuador Cloud Forest Lodges
- Ecuador Amazon Lodges
- Ecuador Luxury Travel
- Ecuador Family Vacations
- Coast / Andes / Galapagos / Amazon guides

==================================================
9. FAQ
==================================================
Required:
- 4 to 6 questions only
- Never exceed 6
- Must target real long-tail search intent
- Must support FAQ schema

Rules:
- Questions must be practical and search-aligned
- Answers should be concise but useful
- Do not add filler FAQs

==================================================
10. FINAL CTA
==================================================
Required:
- Headline
- 1 supporting line
- 2 CTA buttons

Recommended CTA targets:
- Trip Builder
- Related collections
- Route recommendation page
- Contact / inquiry page if appropriate

==================================================
SEO REQUIREMENTS
==================================================

SEO TITLE
- Max 60 characters
- Format:
  [Primary Keyword] | [Value]
- Must be ranking-oriented and CTR-aware
- Avoid generic wording

META DESCRIPTION
- 140 to 160 characters
- Must be high CTR
- Must include specific benefits
- Must match real intent
- Avoid vague filler

H1
- Must align with title
- Slightly simplified for readability

OG / TWITTER
- Use same title and meta description
- Must include the approved OG image when no custom image exists

CANONICAL
- Required

HREFLANG
- Required:
  - en
  - es
  - x-default

VISIBLE BILINGUAL DISCOVERY
- Every page must have crawlable EN / ES links in raw HTML
- These links must be visible in source, not only injected later through navigation JS
- Hreflang is required, but must not be the only bilingual discovery method

SCHEMA (JSON-LD)
Use the correct type depending on page intent:
- Article
- TravelGuide
- TouristTrip

Always include:
- @context
- @type
- name
- description
- url

If FAQ exists:
- Also include FAQPage

OPTIONAL extra fields when relevant:
- headline
- inLanguage
- mainEntityOfPage
- publisher
- image
- author

==================================================
KEYWORD STRATEGY
==================================================
Every page must be built around:
- 1 primary keyword
- 3 secondary keywords

Rules:
- Keywords must match real intent
- No keyword stuffing
- Use naturally in:
  - title
  - meta
  - H1
  - intro
  - H2s
  - FAQ
  - anchor text where appropriate

==================================================
LANGUAGE RULES
==================================================

ENGLISH
- Clean
- Strategic
- Helpful
- No fluff
- No generic travel-blog tone

SPANISH
- Natural LATAM / South American Spanish
- Not literal translation
- Proper accents in visible text
- URLs remain ASCII-safe
- Use only confirmed Spanish URLs from sitemap

==================================================
IMAGE RULES
==================================================
- Hero: 1 image required
- Additional images: optional
- Keep lightweight for performance
- Never leave blank image areas
- Never invent missing image paths
- Use placeholder only when needed:
  https://experienceecuador.com/EE-OG-Image-1.jpg

OG IMAGE RULE
- Default OG image:
  https://experienceecuador.com/EE-OG-Image-1.jpg
- Apply to:
  - og:image
  - og:image:secure_url
  - twitter:image

==================================================
GLOBAL BUILD RULES
==================================================
Use ONLY:
- /assets/css/header.css
- /assets/css/footer.css
- /assets/css/site.css

Do NOT use:
- <style> blocks
- page-level CSS files
- inline JS for shared components
- page-specific JS for shared components

Required mounts:
- <div id="siteHeader" data-current-lang="en"></div>
  or
- <div id="siteHeader" data-current-lang="es"></div>

- <div id="siteFooter"></div>

Include:
- /assets/js/site.js

Approved lightweight include bootstrap may remain when already part of the reference pattern

==================================================
NON-NEGOTIABLE VALIDATION BEFORE OUTPUT
==================================================
- Complete HTML file only
- No partial output
- Title under 60 characters
- Meta description 140 to 160 characters
- H1 aligned with title
- Canonical present
- Hreflang present
- Visible EN / ES raw HTML links present
- Correct schema present
- FAQ schema present if FAQ exists
- Internal links present naturally in the article
- Required global internal links included
- Spanish URLs validated against sitemap
- No fluff
- No broken links
- No empty image blocks
- Global CSS only
- site.js included
- Header mount present
- Footer mount present
- Mobile-friendly structure
- Production-ready without additional edits
