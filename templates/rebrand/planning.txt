PLANNING TEMPLATE (TRIP BUILDER / PLANNING HUB) - SEO UPDATED

PURPOSE
The Planning template is the highest conversion layer outside individual recommendation pages.

It should:
- guide users toward building a trip
- reduce decision fatigue
- connect major content layers: regions, experiences, guides, recommendations, members, and blog content
- act as a bridge between research and action
- maximize SEO for Ecuador planning, itinerary, trip builder, and region-combination queries

REQUIRED SEO FIELDS
Every planning page must include:
- Title (SEO optimized)
- Meta Description
- H1 aligned with the title
- New OG Title (same as title)
- New OG Description (same as meta description)
- New Twitter Title (same as title)
- New Twitter Description (same as meta description)
- New Schema Name (title without the pipe character)
- New Schema Description (same as meta description)

TECHNICAL SEO REQUIREMENTS
- Add canonical URL.
- Add hreflang for English, Spanish, and x-default.
- Add crawlable EN/ES links in raw source HTML. Hreflang is required but must not be the only bilingual discovery method.
- Use index,follow robots meta.
- Use one primary OG/Twitter image relevant to the planning page, not a generic default image when a page-specific asset exists.
- Include JSON-LD with WebPage, FAQPage, and BreadcrumbList.
- WebPage schema description must exactly match the meta description.
- WebPage schema name must use the title without the pipe character.
- JSON-LD must parse cleanly.
- No empty href values.

INTERNAL LINKING REQUIREMENTS
Each planning page should include crawlable links to:
- English and Spanish alternate page versions
- all major region hubs: Galapagos, Coast, Andes, Amazon
- key experience hubs: adventure, nature, wildlife/birding, culture, gastronomy, relaxation when relevant
- country-level guide pages
- best-time/seasonal planning guide
- where-to-stay or recommendations hub where relevant
- Trip Builder CTA, if the page is not the Trip Builder itself

CONVERSION REQUIREMENTS
- Keep the first screen focused on planning action.
- Include a clear primary CTA.
- Include supporting copy that explains how the planner works.
- Include final CTA near the bottom.
- If the page includes a tool, do not bury the tool below excessive intro copy.

1. HERO
Purpose:
- set expectation
- guide user into planning mindset
- make the page purpose clear immediately

Content:
- H1 aligned with the SEO title
- short supporting text
- primary CTA
- raw EN/ES language switch near the top of the page

Example:
H1: Ecuador Trip Planner Build Your Custom Itinerary
Copy: Build your itinerary by choosing regions, experiences, and travel style that match your goals.
CTA: Start Trip Builder

2. PLANNING OVERVIEW
Purpose:
- explain how the site helps users plan more confidently

Content:
- 2 to 3 short paragraphs

Explain:
- how to approach Ecuador planning
- why regions plus experiences matter
- how the platform simplifies decisions

3. CHOOSE YOUR TRAVEL STYLE
Purpose:
- segment users early

Content:
- cards for styles such as adventure, luxury, family, wildlife, culture, relaxation, food, and nature

4. CHOOSE YOUR REGIONS
Purpose:
- guide geographic decisions

Content:
- region cards in this order where possible:
  Galapagos
  Coast
  Andes
  Amazon

5. CHOOSE YOUR EXPERIENCES
Purpose:
- guide activity decisions

Content:
- experience cards linked to crawlable experience pages where available

6. SAMPLE ITINERARIES
Purpose:
- give users realistic examples

Content:
- sample 7-day, 10-day, and 14-day structures where relevant
- mention that shorter trips should focus on fewer regions

7. PLANNING TIPS
Purpose:
- provide practical value and reduce overwhelm

Content:
- pacing guidance
- transfer-day guidance
- seasonal notes
- when to combine Galapagos with mainland Ecuador

8. KEY TRAVEL GUIDES AND INTERNAL LINKS
Purpose:
- strengthen SEO and discovery

Content:
- country guide
- region guides
- best time to visit
- packing list by region
- where to stay
- recommendations hub

9. TRIP BUILDER CTA
Purpose:
- main conversion point

Content:
- CTA to start or continue planning
- copy focused on itinerary personalization

10. FAQ
Purpose:
- answer SEO and conversion questions

Include questions about:
- how many days are needed for Ecuador
- whether Galapagos can combine with mainland Ecuador
- how many regions to choose
- best planning order

11. FINAL CTA
Purpose:
- close with action

Content:
- direct CTA to build, refine, or contact Experience Ecuador

This page should feel like:
- a planning assistant

- a conversion engine
- an SEO-rich hub that links users deeper into the site
