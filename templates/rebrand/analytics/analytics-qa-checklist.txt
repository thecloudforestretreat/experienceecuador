EXPERIENCE ECUADOR ANALYTICS QA CHECKLIST

Use this checklist whenever a page or page pair is updated.

1. PAGE BASICS
- [ ] Correct page type identified
- [ ] Correct language identified
- [ ] Counterpart EN/ES page identified

2. SITEWIDE EVENTS
- [ ] page_view_enhanced supported
- [ ] language_switch_click supported if bilingual page
- [ ] primary_cta_click added where primary CTA exists
- [ ] secondary_cta_click added where secondary CTA exists
- [ ] internal_link_click added where important internal links exist
- [ ] outbound_link_click added where external links exist
- [ ] scroll_depth milestones supported
- [ ] form_start added where form exists
- [ ] form_submit_success added where form exists
- [ ] form_submit_error added where form exists
- [ ] faq_expand added where FAQ accordion exists

3. PAGE-TYPE EVENTS
- [ ] Blog / guide / spotlight events added if relevant
- [ ] Member page events added if relevant
- [ ] Recommendations hub events added if relevant
- [ ] Trip builder events added if relevant
- [ ] Utility / support events added if relevant
- [ ] Partner page events added if relevant
- [ ] Region / experience hub events added if relevant

4. DATA ATTRIBUTES
- [ ] Tracked elements use data-analytics-event
- [ ] Labels use data-analytics-label where relevant
- [ ] Locations use data-analytics-location where relevant
- [ ] Page type is identifiable
- [ ] Region / experience / member / partner parameters are attached where relevant

5. LANGUAGE SWITCH
- [ ] Raw EN/ES links exist in HTML directly below header
- [ ] English aria-label = "Language switch"
- [ ] Spanish aria-label = "Selector de idioma"
- [ ] language_switch_click fires on both links

6. CTA QUALITY
- [ ] Primary CTA is tracked
- [ ] Secondary CTA is tracked
- [ ] CTA location is captured
- [ ] CTA label is clean and readable

7. LINK QUALITY
- [ ] Key internal links are tracked
- [ ] Key outbound links are tracked
- [ ] Member external website / booking / contact links are tracked where applicable
- [ ] Partner funnel links are tracked where applicable

8. FORMS
- [ ] form_start fires on first engagement
- [ ] form_submit_success fires on success
- [ ] form_submit_error fires on visible failure
- [ ] form_name is captured
- [ ] error message captured where relevant

9. SCROLL / CONTENT ENGAGEMENT
- [ ] Scroll milestones are limited to key percentages only
- [ ] No noisy interaction tracking added
- [ ] Content section or related content tracking only added when meaningful

10. NAMING CONSISTENCY
- [ ] No duplicate event concepts with different names
- [ ] Parameter names match the shared analytics standard
- [ ] No one-off custom labels that break reporting consistency

11. FINAL REVIEW
- [ ] Analytics matches implementation standard
- [ ] Analytics matches page-update template
- [ ] Ready for staging QA
- [ ] Ready for GA4 validation later
