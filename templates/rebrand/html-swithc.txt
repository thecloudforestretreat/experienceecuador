STANDARD RAW HTML EN/ES LINKS UNDER HEADER

Use this exact HTML pattern on every bilingual page.

PLACEMENT
- Put it immediately after the site header container.
- It must appear before the hero or main content.

HEADER CONTAINER
<div id="siteHeader" data-current-lang="en"></div>

ENGLISH PAGE SNIPPET
<nav class="rawLangLinks" aria-label="Language switch">
  <a href="https://experienceecuador.com/example-page/" lang="en">English</a>
  <a href="https://experienceecuador.com/es/pagina-ejemplo/" lang="es">Español</a>
</nav>

SPANISH PAGE SNIPPET
<div id="siteHeader" data-current-lang="es"></div>
<nav class="rawLangLinks" aria-label="Selector de idioma">
  <a href="https://experienceecuador.com/example-page/" lang="en">English</a>
  <a href="https://experienceecuador.com/es/pagina-ejemplo/" lang="es">Español</a>
</nav>

RULES
- Keep the class name exactly as rawLangLinks.
- Keep the links as real anchor tags in raw HTML.
- Do not rely on JavaScript-injected language links alone.
- Do not replace this with plain text links.
- The active language pill is handled by data-current-lang plus shared site.css.
