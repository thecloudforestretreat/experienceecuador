- If the approved reference file uses the lightweight bootstrap injection script for header/footer, preserve that same pattern

  - inject("siteHeader", "/assets/includes/header.html")

- Do NOT require /assets/includes/header-es.html
- Do NOT invent a second Spanish-only header include path unless the source file already uses one
- Language handling should come from:

  <div id="siteFooter"></div>
