---

CORE GOAL

Generate standalone recommendation member pages that behave like SEO landing pages, not thin directory listings.

Every page must:
- preserve the global header/footer include system using /assets/includes/header.html and /assets/includes/footer.html
- use SEO-specific meta fields
- use clean bilingual hreflang
- include strong schema
- include analytics attributes
- adapt content blocks to the listing's actual strengths
- avoid false claims and keyword stuffing
- avoid generic one-size-fits-all copy


---

GLOBAL HEADER AND FOOTER INCLUDE RULES

Every generated listing page MUST use the shared Experience Ecuador global includes.

Required mount points:

EN and ES pages both use the SAME shared files:
- /assets/includes/header.html
- /assets/includes/footer.html

There is NO header-es.html and NO footer-es.html for these listing pages.
Do not create language-specific header/footer include paths.

Immediately after <body>:
EN:
<div id="siteHeader" data-current-lang="en"></div>

ES:
<div id="siteHeader" data-current-lang="es"></div>

Immediately after </main>:
<div id="siteFooter"></div>

Every page MUST include this injection script after #siteFooter and before page-specific JavaScript:

<script>
  (function(){
    async function inject(id, url){
      var el = document.getElementById(id);
      if(!el) return;
      var res = await fetch(url, { cache: "no-store" });
      el.innerHTML = await res.text();
    }
    Promise.all([
      inject("siteHeader", "/assets/includes/header.html"),
      inject("siteFooter", "/assets/includes/footer.html")
    ]).then(function(){
      if (!document.querySelector('script[src="/assets/js/site.js"]')) {
        var s = document.createElement("script");
        s.src = "/assets/js/site.js";
        document.body.appendChild(s);
      }
    });
  })();
</script>

Rules:
- Do not hardcode page-level header markup.
- Do not hardcode page-level footer markup.
- Do not use header-es.html or footer-es.html.
- Keep the rawLangLinks language switch directly after #siteHeader.
- Keep /assets/css/header.css, /assets/css/footer.css, /assets/css/site.css, and /assets/css/listing-member-seo.css in the head.
- Load /assets/js/site.js only after the shared header and footer are injected.

SEO FIELD RULES

1. Use:
   {{META_TITLE_EN}} -> <title>, og:title, twitter:title, WebPage schema name
   {{META_TITLE_ES}} -> <title>, og:title, twitter:title, WebPage schema name
   {{META_DESCRIPTION_EN}} -> meta description, og:description, twitter:description, WebPage schema description
   {{META_DESCRIPTION_ES}} -> meta description, og:description, twitter:description, WebPage schema description

2. Do not replace meta titles with {{TITLE_EN}} or {{TITLE_ES}}

3. Do not append "| Experience Ecuador" unless already provided

4. UI fields:
   {{TITLE_EN}} / {{TITLE_ES}} are used for H1, breadcrumbs, CTAs, labels

5. Do NOT use:
   - "best"
   - "top"
   - "number one"
   unless explicitly justified by data

🔥 MAP RULES (FINAL SYSTEM)

THIS IS CRITICAL — DO NOT BREAK THIS

1. IF google_maps_embed_url EXISTS:
   - Render a live iframe map preview
   - Also include an "Open map" button if google_maps_share_url exists
   - Use this only when the URL is a true Google Maps embed URL
   - Never use a maps.app.goo.gl share URL inside an iframe

2. IF ONLY google_maps_share_url EXISTS:
   - DO NOT render iframe
   - Render a clickable map card linking to Google Maps
   - Button text:
     EN: Open in Google Maps
     ES: Abrir en Google Maps

3. IF ONLY latitude + longitude EXIST:
   - Generate link:
     https://www.google.com/maps/search/?api=1&query=LAT,LNG
   - Render a clickable map/location card with that generated link
   - DO NOT render iframe

4. IF NO google_maps_embed_url, NO google_maps_share_url, and NO latitude/longitude EXIST:
   - DO NOT render .mapSplit
   - DO NOT render .mapCard
   - DO NOT render any empty map placeholder
   - Render a normal full-width .section only
   - Use aria-label:
     EN: Location guidance
     ES: Guía de ubicación
   - Include:
     - region
     - destination/location
     - arrival note
     - contact instruction
     - CTA buttons if website_url or whatsapp_url exists
   - Example EN:
     "A public map preview is not available yet, so travelers should contact the property directly to confirm the exact arrival point, current road conditions, and best route before traveling."
   - Example ES:
     "Esta ficha todavía no incluye una vista previa pública del mapa, por lo que los viajeros deben contactar directamente al alojamiento para confirmar el punto exacto de llegada, el estado actual de la vía y la mejor ruta antes de viajar."

5. NEVER:
   - show an empty iframe
   - show a broken map
   - show a blank map card
   - leave a map placeholder
   - invent coordinates
   - fake map content

6. Schema rule:
   - Add GeoCoordinates only when latitude and longitude are provided
   - Do not add GeoCoordinates from guesses
