CRITICAL JSON-LD VALIDATION RULE
Before finalizing any page:
- JSON-LD must parse successfully as valid JSON.
- All schema objects must remain INSIDE the same @graph array.
- Never append a schema object after the closing @graph array or after the closing root object.
- No orphan schema objects may exist outside the root JSON-LD object.
- No trailing commas may exist.
- Schema should be compatible with Schema.org Validator and Google Rich Results Test.

NEVER output this broken pattern:
]
}
,
{
  "@type": "TouristDestination"
}

Correct pattern:
{
  "@context": "https://schema.org",
  "@graph": [
    { ... },
    { ... },
    {
      "@type": "TouristDestination",
      ...
    }
  ]
}

If adding TouristDestination, LocalBusiness, FAQPage, WebPage, CollectionPage, BreadcrumbList, Article, or any other schema object, it MUST be inserted as an item inside the existing @graph array.
